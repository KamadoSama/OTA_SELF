# ZenOTA CLI 🚀

> **The enterprise-grade standard for Expo Over-The-Air (OTA) updates.**

ZenOTA provides a premium, "Elite & Zen" experience for shipping instant updates to your React Native Expo applications without the complexity and costs of traditional pipelines.

[![npm version](https://badge.fury.io/js/zenota-cli.svg)](https://badge.fury.io/js/zenota-cli)

## ⚡️ Quick Start

Install the CLI globally:

```bash
npm install -g zenota-cli
```

### 1. Login

Securely authenticate with your ZenOTA instance. You can use the official Cloud or your own self-hosted server:

```bash
zenota login
```

- **Self-Hosted**: Enter your own API URL (e.g., `https://ota.yourcompany.com/api`)

### 2. Publish

Deploy your changes to the global edge network in seconds:

```bash
zenota publish
```

---

## ✨ Key Features

- **Instant Edge Delivery**: Ship bundles across a global network for millisecond updates.
- **Zero-Config Setup**: Works seamlessly with your existing Expo projects.
- **Selective Rollouts**: Control who gets what update and when.
